# Бесплатный запуск BizPilot (без бюджета на сервер и домен)

## Вариант 1: Облако Render.com (0 ₸/мес, свой адрес https://bizpilot-xxxx.onrender.com)
1. Зарегистрируйтесь на **github.com** и загрузите туда содержимое папки `bizpilot` (приватный или публичный репозиторий).
2. Зарегистрируйтесь на **render.com** (вход через GitHub, банковская карта для `Free` тарифа не требуется).
3. Нажмите **New +** -> **Web Service** -> выберите ваш репозиторий `bizpilot`.
4. Render сам найдёт `Dockerfile` и `render.yaml`. Нажмите **Create Web Service** (план `Free`).
5. Через 2–3 минуты вы получите рабочую ссылку вида `https://bizpilot-xxxx.onrender.com` с бесплатным SSL!

> **Важно про бесплатный тариф Render:**
> - На тарифе Free сервер засыпает после 15 минут без активности (первый запрос просыпается за ~20–30 секунд).
> - При пересборке (deploy) локальный файл SQLite на бесплатном диске сбрасывается. Когда появятся первые клиенты, можно подключить бесплатную внешнюю БД (например, Turso / Neon / Supabase) или перейти на платный диск ($1–7/мес).

## Вариант 2: Показать клиентам прямо со своего ПК (Cloudflare Tunnel — 0 ₸, ничего не сбрасывается)
Если ваш ПК включён:
1. Скачайте бесплатный `cloudflared` (официальный инструмент Cloudflare).
2. Запустите:
   ```bash
   cloudflared tunnel --url http://localhost:8123
   ```
3. Вы сразу получите временную публичную HTTPS-ссылку `https://....trycloudflare.com`, которую можно отправлять знакомым для теста!
